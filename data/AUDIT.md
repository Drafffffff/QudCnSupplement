# 静态语料审计

依据游戏 2.0.212.31 的官方 `ExampleLanguage` XML，统计 **25,090 个非空、带 ▶ 导出标记的可本地化字段**。原包与增量合计可为每个字段找到值；这表示语料字段可用性达到 100%，**不表示整个游戏汉化完成或翻译正确率 100%**。

生成 25 个 `Lang="CN"` 增量 XML，实际写出 5,102 个字段。保留原简中补丁，补充 Mod 必须排在原包之后加载。一般只写入缺失或需要替换的字段；`Load="Replace"` 集合必须附带原有兄弟项，避免清空未修改的姓名音节等条目。繁中语料使用 OpenCC `t2s` 转简体，仅转换字符，不将其误称为人工审校。

来源分类见 `coverage-summary.json`。603 个字段使用人工维护的映射；其余新增内容使用现有简中精确/ID/文本回退、繁中转换，或保留模板、快捷键、标识符和姓名音节。`unresolved.json` 当前为空。

## 已验证

- 所有生成 XML 可由 XML 解析器读取。
- 生成 XML 没有遗留 ▶ 导出标记。
- 603 个新增人工映射字段及繁中回退新译文的 `=变量/语法操作=` 占位符与源文本的多重集合一致；包含变量重复次数。第二轮修改原包的 256 个字段另保留合法中文选择器参数与中文省略，不能以完整 token 字面相同作为语法合法性的唯一判据。
- 原包复核后仍有 501 个字段与当前英文导出占位符不完全一致，保留并记录于 `token-warnings.json`，合法的中文 selector 参数不恢复为英文；268 项保持变量头部一致，233 项为中文语法省略或结构差异，需要结合运行时复核。
- `snapshot-sha256.json` 记录输入文件哈希，`audit-fields.json` 逐字段记录来源、译文和是否写出。

## 不能据此保证的范围

`existing-mixed-latin.json` 记录原简中译文中 475 个仍含可疑拉丁文本的字段，其中大量是书籍的专有名词、数学家姓名、格式符号、缩写，也可能有真正的漏译。该清单是待人工审核项，不能全部算作漏译或全部排除。

XML 导出以外的 C# 拼接文本、程序生成名称、`historyspice` JSON、未导出字符串、运行时格式处理、其他 Mod 文本，以及术语一致性与排版均不在本次静态字段统计内。运行时必须另行测试，不能用本报告代替实测。

## 复现

在项目目录安装 `opencc-python-reimplemented`，然后执行：

```sh
python3 tools/build_corpus.py --upstream ../CAVES_OF_QUD/upstream
```

构建离线运行。输出为 `mod/languages/lang-CN/*.supplement.CN.xml` 与本目录 JSON 审计文件。任何修改都应编辑 `manual-translations.json` 或生成器后重新生成，不直接维护生成 XML。

## 第二轮原包修复

新增 `manual-overrides.json`，逐条保存文件、稳定节点路径、英文源文、修改前译文、修改后译文和原因。生成器严格检查源文及修改前基线；输入变化时立即失败，避免错误套用覆盖。

实际修改 256 个既存字段，重点覆盖技能属性描述、物品说明、泡菇及族群名称、教程和手册英文标题、界面标签，以及分散在颜色标签中的鳄皮软鞋与伊萨查里旗帜文字。修复了变量终止符丢失，如 `=min.range#max%` → `=min.range#max=%`、`=bonus%` → `=bonus=%`、`%=year%` → `%=year=%`。源导出本身的字面 `pronouns` 片段被翻译为“代词”，并保持原 `isNew` 选择器结构。

剩余拉丁片段分类见 `review-classification.json`，包括选项枚举键、派系/关系复合键、命令与键帽、型号与罗马数字、文件名和技术缩写、署名与第三方原始许可证，以及书籍和世界设定中的专名/造词。分类是可复核的审阅队列，不把全部剩余条目自动认定为“必须保留”。
